# 🌼 Word Cottage

Уютная браузерная игра на двоих для изучения английского. Подходит для GitHub Pages, не требует сборки, npm или сервера для локального деморежима.

## Что уже работает

- Собственная пиксельная сцена: домик, сад с шестью грядками, котик и покупки, которые появляются на поляне.
- 50 слов на темы «Еда», «Дом», «Вещи», «Действия», «Чувства».
- Две сложности: A0 (перевод, картинка, сборка букв) и A2–B1 (пропуски, порядок слов, контекст).
- Пять упражнений на игрока ежедневно, +10 монет за правильное завершение, максимум 50 в день.
- Подсказка после ошибки, повтор без штрафа, повторы слов через 1/3/7 дней.
- Слова на грядках: семя → росток → цветок. Можно пересаживать изученные слова.
- Питомец с настроением и именем; магазин из шести предметов.
- Ежедневное слово-подарок между игроками.
- Локальная демоверсия на одном устройстве с переключением двух профилей и `localStorage`.
- Настоящий общий мир через Firebase Anonymous Authentication + Firestore: код комнаты на 7 символов, максимум два игрока, синхронизация изменений, транзакции при покупке и наградах.

## Быстрый запуск

1. Скопируй **все файлы из папки** в корень репозитория GitHub (важно, чтобы `index.html` был именно в корне).
2. Открой **Settings → Pages** → `Deploy from a branch` → ветка `main`, папка `/ (root)` → **Save**.
3. Запусти сайт по адресу `https://ИМЯ.github.io/РЕПОЗИТОРИЙ/`.
4. Без настройки Firebase игра уже запускается, но **только как локальная демоверсия**. На странице создания мира появится это пояснение.

Можно также открыть `index.html` двойным щелчком для демонстрации; для онлайн-режима используй опубликованный HTTPS-сайт или localhost.

## Совместный режим (два телефона)

Для синхронизации потребуется бесплатный тариф Firebase (проверь действующие лимиты сервиса). Настройка занимает несколько шагов:

1. Создай проект в [Firebase Console](https://console.firebase.google.com/).
2. В **Build → Authentication → Sign-in method** включи **Anonymous**.
3. В **Build → Firestore Database** создай базу данных. При настройке выбери подходящий регион.
4. Открой вкладку **Rules** и вставь содержимое файла `firestore.rules`, затем нажми **Publish**. Не оставляй базу с открытыми тестовыми правилами!
5. Перейди в **Project settings → General → Your apps**, добавь Web app (`</>`), скопируй выданный объект `firebaseConfig`.
6. Открой `firebase-config.js` и замени `null` на свой объект, например:

   ```js
   window.WORD_COTTAGE_FIREBASE_CONFIG = {
     apiKey: '...',
     authDomain: 'project-name.firebaseapp.com',
     projectId: 'project-name',
     appId: '...'
   };
   ```

7. В **Authentication → Settings → Authorized domains** добавь домен GitHub Pages (`имя.github.io`), если он ещё не разрешён.
8. Загрузи обновлённый `firebase-config.js` в GitHub. Обнови страницу. Теперь можно создать мир, передать код второму игроку и присоединиться с другого устройства.

**Важно:** настройки Web App не являются секретным серверным ключом; безопасность обеспечивается Firestore Security Rules. Правила в репозитории — базовая защита личного доступа и гостевого вступления, но это MVP: для публичной игры с денежной экономикой и враждебными пользователями понадобятся более строгие проверки начислений на сервере (Cloud Functions / App Check). В закрытой игре на двоих достаточно для знакомства с механикой.

## Как сохраняются данные

В деморежиме — в `localStorage` браузера. В онлайн-режиме — документ `rooms/КОД` в Firestore и анонимный Firebase UID каждого участника. Каждый пользователь видит свой набор упражнений, общий сад и покупки. Действия проходят через транзакции, чтобы монеты не перезаписывались при одновременных покупках.

**Анонимный вход привязан к браузеру.** Если очистить его данные или открыть игру в инкогнито, восстановить старый профиль без отдельной системы привязки аккаунта нельзя. Не удаляй данные сайта в онлайн-режиме. Участники комнаты могут видеть учебную статистику другого игрока, но не содержимое отдельных ответов (история ответов не сохраняется).

## Файлы

| Файл | Для чего |
|---|---|
| `index.html` | Экран игры и модальные окна |
| `style.css` | Адаптивный интерфейс |
| `data.js` | Словарь из 50 слов |
| `app.js` | Игровая логика, пиксельная сцена и Firebase |
| `firebase-config.js` | Твой Web config Firebase (`null` по умолчанию) |
| `firestore.rules` | Правила доступа Firestore — вставить в консоль |

Проект полностью на HTML/CSS/JS, без внешних игровых ассетов и платных библиотек. Шрифты подгружаются с Google Fonts; если сервис недоступен, используются стандартные.

### Ограничения MVP

Словарь подготовлен вручную, не используется генеративный ИИ для оценки свободных ответов. Голос берётся из встроенного синтеза речи браузера и может отличаться. Для multiplayer требуется самостоятельная настройка Firebase; без неё разные устройства не обмениваются сохранениями.
